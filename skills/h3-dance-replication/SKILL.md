# H3 舞蹈复刻

把参考片当作动作、队形、镜头节奏和音轨来源，把角色身份、服装与场景替换成用户指定内容。默认目标是一次生成后立即交付视频，不追加成片质检、抽帧、音轨比对或自动重抽。

## 路由边界

- 单人参考视频只替换人物，并保持原场景、镜头和音频时，使用 [`h3-character-migration`](../h3-character-migration/SKILL.md)；它支持持久分段、Motion Context 和断点恢复。
- 多人映射、固定编队、指定主舞/站位、目标人数变化或同时换背景时，使用本技能。
- 本技能不把一次 H3 Ref2VA 生成宣称为不限时长。需求超出当前 Profile 时长或引用上限时，在付费生成前明确告知限制。
- 普通剪辑、纯原创舞蹈或只去水印不走本技能。

## 先确定任务合同

从用户请求与实际素材中整理：

- 参考舞蹈视频。
- 目标角色图、精确人数及其编队槽位映射；用户指定主舞、中央位、前后排或其他固定位置时一并记录。
- 新背景要求，以及必须排除的原背景、水印、Logo、文字和原人物元素。
- 时长、画幅与生成步数。用户未指定的竖屏短视频默认 9:16，并使用当前可用 H3 Profile 的 4-step Turbo LoRA。
- 音频策略。默认完整复用参考片音轨，不新增对白、旁白、音乐、环境音或音效。
- 用户可直接访问的唯一输出路径，不覆盖先前 take。

## 生成前只做必要分析

1. 用 `ffprobe` 获取参考片时长、分辨率、帧率和音轨信息。
2. 在临时目录抽取少量代表帧，识别舞者数量、编队槽位、主舞者、队形变化、镜头切换、原背景和水印位置。这是提示词编译所需的输入分析，不是生成后质检。
3. 若参考片含音频，用 `ffmpeg` 提取为临时 WAV。H3 的视频参考预处理可能移除音频，因此必须把提取音轨作为独立有序音频引用接入。
4. 用 `h3ctl doctor` 与 `h3ctl profile show PROFILE_ID` 确认服务、Profile、步数和 LoRA。临时 SSH 凭据不得写入仓库、配置、命令历史或交付文本。

所有中间帧与音频放在临时目录，不复制进项目仓库。

## 固定接线

1. 先接全部目标角色图。按开场编队从前排到后排排序，同一排从画面左到右；若用户定义了角色或槽位编号，以其明确顺序为准。
2. 再接参考舞蹈视频。
3. 最后接独立提取的参考音轨。

为每个角色建立独立 Subject 和稳定槽位 ID，并写清每个源舞者或舞蹈角色到目标角色的一一替换关系。声明精确人数，禁止身份融合、复制、增员、消失和非编舞要求的串位。

编译新提示词时读取 [舞蹈复刻提示词骨架](references/prompt-pattern.md) 和同仓库的 [`h3-ref2va-prompt-compiler`](../h3-ref2va-prompt-compiler/SKILL.md)，并保持接线与硬约束不变。

## 动作、镜头与背景迁移

- 从参考视频复制舞步、脚步、重心、手势、群舞同步、镜头高低、切点和节奏；不复制源人物身份、服装或场景。
- 竖屏适配时保持用户要求的全部角色可见，并保留主次层级、前后排和屏幕方向。
- 新背景必须正向描述为唯一目标环境，同时排除原背景的标志性物件。
- 明确写入无水印、无 Logo、无字幕、无可见文字，尤其排除用户指出的原水印位置。
- 角色图只在实际查看后才能按多视图 Sheet 解读；单人全身照不得擅自说成三视图。

## 用 h3ctl 生成

按当前 Profile 和引用数调整命令：

```bash
h3ctl --context CONTEXT --output json generate video \
  --mode r2v \
  --profile minimax-h3-ref2va \
  --prompt-file PROMPT.txt \
  --ref CHARACTER_01.png \
  --ref CHARACTER_02.png \
  --ref SOURCE.mp4 \
  --ref SOURCE_AUDIO.wav \
  --duration SECONDS \
  --aspect-ratio 9:16 \
  --steps 4 \
  --seed -1 \
  --wait --wait-timeout 2h --poll-interval 5s \
  --download OUTPUT.mp4
```

`--ref` 中的角色图按稳定编队槽位重复传入，数量由用户角色和 Profile 限额决定，不是固定三个引用。用户指定步数、画幅、种子、人物数量或 Profile 时，以用户要求为准。任务运行期间定期给简短状态更新；不因生成耗时自行取消或重复提交。

## 直接交付

任务成功并下载后，只确认命令返回成功且输出文件存在，随后立即用绝对路径展示并提供文件：

```markdown
![生成视频](/absolute/path/output.mp4)

[下载视频](/absolute/path/output.mp4)
```

默认不抽帧、不做音轨相关度或媒体参数报告、不自动生成第二个 take。只有生成失败、文件未下载，或用户明确要求检查/返修时，才进入诊断或成片复核。成功后停止临时 SSH 隧道并删除临时素材；不要删除用户原始文件或已交付视频。
